# 태블릿 사용 타임아웃 게시판 (데스크톱 앱)

브라우저 없이 윈도우 컴퓨터에서 별도 창으로 띄우는 버전입니다. 같은 화면을
Electron으로 감싼 것으로, 내용(이름 목록·30분 타이머 로직)은
`games/tablet-timeout/index.html`과 동일합니다.

## 사용자 기능

- 일반 프로그램 창처럼 최소화 / 최대화 / 닫기 버튼 사용 가능
- 창을 닫아도 완전히 종료되지 않고 시스템 트레이(알림 영역)에 남아있다가,
  트레이 아이콘을 클릭하면 다시 열립니다.
- 상단의 "📌 항상 위 고정" 버튼(또는 트레이 우클릭 메뉴)으로 다른 창 위에
  항상 떠 있는 위젯처럼 고정할 수 있습니다.
- 트레이 메뉴의 "종료"를 눌러야 완전히 꺼집니다.

## 개발자용: .exe로 빌드하는 방법

이 폴더는 소스 코드만 저장소에 있고, 빌드 결과물(설치 파일)은 git에
커밋하지 않습니다. 아래 명령으로 직접 빌드합니다.

```bash
cd desktop-app/tablet-timeout-widget
npm install
npm run dist:win
```

빌드가 끝나면 `dist/` 폴더에 다음 파일이 생성됩니다.

- `태블릿 타임아웃 게시판 Setup x.x.x.exe` — 더블클릭 설치형 (설치 후 시작
  메뉴/바탕화면 바로가기 생성)
- `태블릿 타임아웃 게시판 x.x.x.exe` (portable) — 설치 없이 바로 실행

윈도우가 아닌 환경(Linux/Mac)에서도 `electron-builder`가 크로스 빌드를
시도하지만, 정식 배포용 exe는 가능하면 Windows 환경에서 빌드하는 것을
권장합니다.

## 아이콘 교체

`build/icon.png`, `build/icon.ico` 파일을 원하는 이미지로 바꾸면 앱 아이콘이
바뀝니다 (ico는 16~256px 여러 크기를 포함해야 합니다).
